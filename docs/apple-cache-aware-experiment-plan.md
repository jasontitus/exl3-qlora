It supersedes the prior fixed learning-rate/rank/depth sequence, preserved in [the historical plan](apple-cache-aware-experiment-plan-history-2026-10-15.md). ## What counts as improvement

For each attempt, record valid response and replay, source/ABI acceptance, compilation, all required numerical cases, and timing only after correctness passes. Keep queue, memory and transport failures separate from model failures. Compare adapters by the number of usable faster kernels on the same completed tasks and budget; show missing coverage and failures. A kernel must also beat the task's supplied baseline implementation to count as an optimization, not merely outperform a worse model sample.

Use the existing qualified timing backend with matching device, workload, precision and cache conditions. Reuse the existing timing policy: five warm-up batches per variant, 30 interleaved paired rounds, 100 dispatches per batch across its 12 declared workloads. Report every target shape and regression, and recheck promising small margins. A future shorter screen must be separately labeled exploratory rather than silently replacing that policy. A repeatable improvement of at least 5% on the declared target workload is a practical initial success target; a smaller or unstable difference is inconclusive, not a win. Never select only the fastest shape after seeing results. Do not turn the report's descriptive median ratios into a certified speedup; use actual backend timing evidence. Baseline/golden controls must show that the task and workload admit a measurable optimization.

One improved task is an encouraging provisional result. Confirm on a second distinct task family before describing a direction as broadly useful. This is a practical screen, not a promise of statistical certainty or unseen-domain generalization. Once repeated task results guide training choices, call those tasks development tests; keep a small unused confirmation task for the selected adapter. Protected16 stays unchanged and is not repeatedly used for selection.
